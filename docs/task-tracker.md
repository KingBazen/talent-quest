## How to use this document

1. **Before starting work:** read the relevant phase + tasks. Mark tasks `IN PROGRESS` and add yourself to `Assigned Agent`.
2. **While working:** keep tasks accurate. If a task expands, split it. If a task is no longer applicable, mark `DROPPED` with a one-line reason.
3. **After finishing:** mark `DONE` only if acceptance criteria are met. Update the Phase Tracker’s `Progress %` and the **Current Progress Summary** at the bottom.
4. **Never fake progress.** If something is unfinished, it’s not `DONE`.
